# Document Adapter

## Task Package

- Identify source documents, target format, template, language, and audience.
- Define content boundaries, style requirements, page or slide constraints, and accessibility needs.
- State whether tracked changes, comments, citations, or redlines are required.
- Specify visual rendering and inspection requirements.

## Submission Report

- List generated documents and preview or rendered artifacts.
- Record formatting, pagination, font, image, table, and CJK checks.
- Identify any location that still requires human review.
- State whether a readable text report must accompany the binary document.
